# 葳格高中實習課程 - 材料採購統整系統

## 網站連結
https://johnnywang885-gif.github.io/material-purchase-system/

## 功能說明

### 1. 各組輸入
- 各組填寫日期、星期、班級、組別、課程名稱、產品名稱
- 新增多筆材料清單（品名、規格、單位、數量、備註）
- 儲存後自動存入 localStorage，關閉網頁資料不消失

### 2. 快速匯入（文字自動解析）
- 將圖片中的需求文字複製貼上，系統自動辨識：
  - 組別（如：第五組）
  - 日期（如：3/16、3月16日）
  - 星期（如：(一)）
  - 產品名稱（材料清單前的短行文字）
  - 材料清單（品名 + 數量 + 單位，如：砂糖 24g）
- 支援「解析並帶入表單」或「一鍵解析並儲存」

### 3. 彙整總表
- 依日期分組顯示
- 相同材料自動合併加總數量
- 顯示需求組別來源

### 4. 列印採購單
- 產生正式「崴格高級中學實習課程材料採購單」格式
- 跨日期彙整所有材料
- 可直接列印或匯出

## 使用方式

### 直接使用
1. 雙擊 `index.html` 用瀏覽器開啟即可
2. 無需安裝任何軟體

### 部署到 GitHub Pages
1. 建立 GitHub Repository
2. 將 `index.html` 推送到 `master` 分支
3. 建立 `gh-pages` 分支並啟用 GitHub Pages
4. 網址格式：`https://[username].github.io/[repo-name]/`

## 技術架構

- **前端**：HTML + CSS + JavaScript（單一檔案）
- **資料儲存**：localStorage（瀏覽器端儲存）
- **部署**：GitHub Pages
- **無後端依賴**：純前端應用程式

## 注意事項

- 資料僅儲存在使用者瀏覽器的 localStorage 中，各裝置資料獨立
- 如需跨裝置同步，需自行擴充後端功能
- 建議使用 Chrome、Edge 或 Safari 瀏覽器
